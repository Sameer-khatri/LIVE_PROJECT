AuthSentry ITDR — Project Overview

Autonomous Identity Threat Detection & Response Platform (Enterprise Cybersecurity)

1. What is this project in simple words?

Imagine a company where 1,428 employees use their laptops and phones to log in to work every day. AuthSentry is like a super-smart digital security guard that watches every single login in real-time.

The 1-Sentence Summary:
"AuthSentry protects companies from hackers who steal passwords by analyzing the physical behavior of logins (speed, location, and device habits) and automatically kicking hackers out in less than 38 milliseconds."

2. Why do we need it? (The Problem it Solves)

In modern cybersecurity, hackers rarely break through firewalls; they simply steal an employee's password through phishing emails or darknet data leaks.

The Old Way (Fails)

Standard login screens only check: "Is this password correct?" If a hacker enters the stolen password, the system lets them right in, thinking they are the employee.

The AuthSentry Way (Succeeds)

AuthSentry checks behavior and physics: Even if the password is correct, if an employee logs in from San Francisco and then 8 minutes later logs in from Germany, that is physically impossible (Mach 7 flight speed). AuthSentry instantly revokes the session!

3. Key Concepts Explained Simply

  • ITDR (Identity Threat Detection & Response): Software dedicated to protecting user accounts, tokens, and identity credentials rather than just hardware servers.
  • Impossible Travel: When two consecutive logins occur from distant locations faster than commercial airplane flight speeds (900 km/h).
  • Credential Spraying / Password Guessing: When a hacker uses an automated bot script to try hundreds of passwords in a few seconds.
  • MFA Push Fatigue: When a hacker spams dozens of approval popups to an employee's phone at night hoping they click "Accept" just to make the phone stop buzzing.
  • Autonomous Mitigation: The software acts instantly on its own (invalidating stolen cookies, banning hacker IPs) without waiting for a human engineer to wake up.

4. Which Page is What? (The 5 Application Tabs)

Tab 1: Security Dashboard Badge: HQ

What it is: The main executive command center showing the overall health of the entire enterprise.

  • Threat Detection Matrix: 5 interactive cards where you can test live attack simulations (Impossible Travel, Password Guessing, Phone Spam, Tor Relays, Normal Safe Day). Clicking any card runs a live evaluation scan!
  • Concentric Living Arc Gauge: Visualizes the company's danger level (22% = Safe & Nominal) and authentication distribution (68% SSO, 21% Hardware Keys).
  • Radar Vulnerability Map: A 6-axis web graph pointing out which attack categories are safe or elevated.
  • Hacker Speed Card: Calculates the exact km/h velocity between logins.
Tab 2: History Tree Badge: 10 Hubs

What it is: An interactive visual archive and search engine for forensic investigation.

  • 10 Archive Hubs: Organizes company security history into clean branches (User Records, Login History, Device History, IP History, etc.).
  • Forensic Dossier: Clicking an employee (like Sarah Chen) pulls up her account threat score, login history, and a Plain English AI Summary of why her account was flagged.
Tab 3: Recent Activity Badge: Live Feed

What it is: The live black-box flight recorder streaming authentication packets as they happen.

  • Reload Latest Event Button: Allows you to manually poll and fetch the latest live authentication packet from Dublin, Tokyo, or Austin with audio feedback.
  • Live Ingestion HUD: Displays real-time WebSocket connection status and throughput (18.4 messages/sec).
  • Raw JSON Payload Viewer: Clicking any event row expands its forensic breakdown and shows the exact cryptographic token and headers.
Tab 4: Block & Log Out Badge: Mitigate

What it is: The emergency response and containment operations center.

  • Targeted Session Revocation: Shows compromised user sessions (e.g., Sarah Chen on Frankfurt IP) with a "Kill Session Now" button that invalidates stolen cookies in under 38 milliseconds.
  • Firewall Blacklist: Shows banned hacker IPs and allows entering new IP/CIDR blocks to block malicious subnets.
  • Emergency Global Killswitch: A dual-tier button to either revoke flagged accounts or log out all 1,428 employees during a company-wide emergency.
Tab 5: Settings & Rules Badge: v2.4

What it is: The policy and sensitivity calibration studio.

  • Travel Velocity Slider: Set the airplane speed limit (default 800 km/h).
  • Wrong Password Tolerance: Set how many failed attempts trigger a lockout (e.g. 5 fails in 30s).
  • Automated Containment Switches: Toggle autonomous token revocation and firewall blacklisting.

2

3
Navigate to Tab 3 (Recent Activity):

"Here is our live incident feed. It shows events arriving in real-time. I can click 'Reload Latest Event' to poll the edge gateway and see verified logins from Dublin, Tokyo, and London, proving the company traffic is live."

4
